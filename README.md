# Timer conducteur VINCI Centre-Est

Site statique (un seul fichier `index.html`) : timer de conducteur avec validation,
dépassement en rouge inversé, boutons Retour / Passer, état conservé au rechargement.

## Déploiement sur Vercel depuis GitHub
1. Mettre `index.html` et `README.md` à la racine du dépôt GitHub.
2. Sur vercel.com : **Add New → Project**, importer le dépôt.
3. Framework Preset : **Other**. Laisser Build Command et Output Directory vides.
4. Cliquer sur **Deploy**.

Chaque `git push` sur `main` redéploie automatiquement le site.
